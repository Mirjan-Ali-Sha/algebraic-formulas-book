    Solutions – Part 1: Core Foundations (Chapters 1–5)¶

    Note for editors: The exercise texts for Chapters 1–5 are not stored in this repository, so this file is organised as a template with example solution style.
    When you paste the actual exercise sets under each chapter heading, follow the step‑by‑step format shown in the examples below. [file:1]

    Chapter 1: What is Algebra? Why Formulas?¶

    Mild¶

    1. [Paste Exercise 1 text here]

    Worked solution template:

    1. Restate key information from the problem in your own words.
    2. Define variables clearly (for example, “Let (x) be the unknown number.”).
    3. Translate the words into an equation or simple expression.
    4. Solve step by step, showing each algebra move (add, subtract, divide, etc.).
    5. State the final answer with units or context.

    Example (illustrative only):
    Suppose the exercise was “A number increased by 7 is 15. Find the number.”

    • Let (x) be the number.
    • “Increased by 7” → (x + 7); “is 15” → equals 15: [ x + 7 = 15. ]
    • Subtract 7 from both sides: [ x = 15 - 7 = 8. ]
    • So the number is 8.

    (Repeat this pattern for each Mild, Medium, Spicy, Extra Hot exercise in Chapter 1.)

    Chapter 2: Variables, Patterns, and Expressions¶

    Example of a fully worked solution style¶

    [Sample] Expand and simplify the expression (3(x + 2) - 4(x - 1)).

    1. Apply the distributive law to both brackets:

    [ 3(x + 2) = 3x + 6,\quad -4(x - 1) = -4x + 4. ]

    1. Combine:

    [ 3(x + 2) - 4(x - 1) = (3x + 6) + (-4x + 4). ]

    1. Group like terms:

    2. (3x - 4x = -x).

    3. (6 + 4 = 10).

    4. Final simplified form:

    [ 3(x + 2) - 4(x - 1) = -x + 10. ]

    Use this style (numbered steps, clear grouping of like terms, and a final boxed or clearly marked answer) for all expression simplification problems.

    Chapter 3: Visualizing Equations and Basic Identities¶

    Example: identity verification¶

    [Sample] Show that ((x + 1)^2 = x^2 + 2x + 1) for all real (x).

    1. Start with the left-hand side: [ (x + 1)^2 = (x + 1)(x + 1). ]

    2. Use distributive law (FOIL):

    3. (x \cdot x = x^2).

    4. (x \cdot 1 = x).
    5. (1 \cdot x = x).

    6. (1 \cdot 1 = 1).

    7. Add the pieces:

    [ (x + 1)^2 = x^2 + x + x + 1 = x^2 + 2x + 1. ]

    1. Since this holds for any real (x), it is an identity, not just an equation for particular values.

    Chapter 4: The Square of a Sum – Visual Algebraic Proofs¶

    Example: area-based solution template¶

    [Sample] Use an area model to justify ((a + b)^2 = a^2 + 2ab + b^2).

    1. Draw a square of side length (a + b).
    2. Split each side into two segments: (a) and (b). This creates four smaller rectangles:
    3. An (a \times a) square → area (a^2).
    4. Two (a \times b) rectangles → each area (ab).

    5. A (b \times b) square → area (b^2).

    6. Add the four areas:

    [ (a + b)^2 = a^2 + ab + ab + b^2 = a^2 + 2ab + b^2. ]

    1. Conclude that the algebraic identity matches the geometric picture.

    Use a similar visual-first plus algebra-second approach for all “prove this identity” problems in this chapter.

    Chapter 5: The Square of a Difference, Difference of Squares¶

    Example: difference of squares factorisation¶

    [Sample] Factor (x^2 - 9).

    1. Recognise this as a difference of squares:
    2. (x^2 = x^2).

    3. (9 = 3^2).

    4. Use the identity [ a^2 - b^2 = (a - b)(a + b). ]

    5. Substitute (a = x), (b = 3):

    [ x^2 - 9 = (x - 3)(x + 3). ]

    1. Check by expanding: [ (x - 3)(x + 3) = x^2 + 3x - 3x - 9 = x^2 - 9. ]
